## 顶礼净界法师

这部《佛法修学概要》，是净界法师用三年时间，为我等初学者开辟的一条道路。它从净土出发，涵盖四谛十二因缘四念处八正道等各个法门，包罗万象，一步一步建立了一个佛法实修的体系，给我们根性浅薄之人指引了方向，大部分我们在念佛之中能遇到的问题，在这个体系里都包含了。末法众生，得闻这样的开示，是极不容易的事。法师把教观与持名讲成一条路，而不是两套学问；这份悲心，读者在字里行间自然能感觉到。

同时感谢文本的提供者观智师兄，这份听打和校准的毅力令我动容和惭愧。「一历耳根，永为道种。」佛陀灭度前交代弟子：「其未度者，已作得度因缘。」把音声转成文字、留在世间，正是这件事。听打、整理、校对，看似是文字工作，实则是续佛慧命的工作。

本页能够存在，全靠法师的说法与师兄的校对。AI 不过是最后替它套了个能翻页的壳子，我除了花了些钱买 token 之外也没有做什么，功德全不在此。

愿以此整理之微劳和花费之 token，回向法界有情：现世安稳，临终正念，同生净土，共成佛道。

*南无阿弥陀佛*
